### Product 2: Cloud Mug (cloud-line)
- **SKU:** CLOUD-MUG-BLUE, CLOUD-MUG-PINK
- **Category:** Handcrafted ceramic mugs (cloud-line)
- **Price:** Research-recommended launch MSRP $36–39
- **Status:** Researched
- **Positioning:** Mid-premium handcrafted cloud-shaped mugs with cute/soft aesthetic for daily ritual and gifting.

#### Key Features
- Hand-thrown ceramic form with cloud silhouette
- Variants: Blue Cloud Mug, Pink Cloud Mug
- Daily-use capacity target: ~10oz+ (to differentiate from common 6–7oz novelty mugs)
- Microwave and dishwasher-safe framing (confirm final spec before publishing)
- Gift-ready packaging with collectible color pair potential

#### Proof Points
- East Fork-style proof language for daily-use ritual ownership and hand-feel
- Kanyon ($70) and Maison by Tai set examples show premium but less affordable cloud competition
- Koythin/Tessco/Sumind mass-market cloud mugs mostly 6.5–10oz with heavy price pressure in low tier
- Market data: global mug market ~USD 28.09B (2024), showing large category demand (Data Bridge)

#### Common objections
1. "Too expensive for a mug" → Reframe with daily ritual and long-term utility
2. "I can get cloud mugs on Amazon" → Reframe on tactile quality + real use size + glaze variation
3. "Too small" → Pre-empt with 10oz+ framing and mug size context
4. Shipping/fragility concerns → Emphasize protected packaging + replacement policy

#### Top angles
- Morning ritual transformation: "What if your morning started with a cloud?"
- Gift that people actually use: solves mug graveyard problem
- Collector angle: blue + pink pair and possible drop strategy

#### Offer architecture
- **Entry:** Single mug
- **Core:** Mug + saucer + gift note card
- **Premium:** Pair bundle + matching accessories

### Bundle Strategy
- Start with cloud-line core bundle ladder (single / pair)
- Introduce seasonal/glanceable accessory add-ons (coaster/trivet/saucer set)
- Use gift-first bundles for holidays and Valentine/housewarming windows
