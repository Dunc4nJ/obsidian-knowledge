On the Rectilinear Crossing Number

The following table contains lower bounds and best known minimizing examples (upper bounds) for the rectilinear crossing number of the complete graph of a set of n points in the plane (in general position; n up to 100). The examples for n=34,38,42,48,51 are by Henning F. Jensen [personal communication 2005-2009]). The set for n=40 is based on the realization of an abstract order type by Manfred Scheucher. Some of the examples for n=3k are also based on [3-symmetric and 3-decomposable drawings of K_n by B. M. Ábrego, M. Cetina, S. Fernández-Merchant, J. Leaños, and G. Salazar in Discrete Applied Mathematics 158 (2010), no. 12, 1240-1258]. Many of the larger examples (in the range 46-99) are from (or based on examples from) [Computational search of small point sets with small rectilinear crossing number. by Ruy Fabila-Monroy and Jorge Lopez, Journal of Graph Algorithms and Applications 2014]. Especially the set with n=75 points is from there, which provides the currently best upper bound of 0.380473 for the rectilinear crossing constant.

For the computation of the lower bounds we used a Mathematica-notebook, which you can download here to make your own experiments.

Several of the lower bounds are summarized from recent papers. Tight values for up to n=27 are from [The maximum number of halving lines and the rectilinear crossing number of K_n for n<=27, Bernardo M. Abrego, Silvia Fernandez-Merchant, Jesus Leanos and Gelasio Salazar, Electronic Notes in Discrete Mathematics, 30:261--266, 2008]. Recently improved lower bounds for larger values of n are taken from [On <=k-edges, crossings, and halving lines of geometric drawings of K_n. by Bernardo M. Abrego, Mario Cetin, Silvia Fernandez-Merchant, Jesus Leanos and Gelasio Salazar] and for n=30 from [Point sets that minimize $(\le k)$-edges, $3$-decomposable drawings, and the rectilinear crossing number of $K_{30}$, Mario Cetina, César I. Hernández, Jesus Macias Leanos, Cristobal Villalobos, Discrete Mathematics, 311 (2011) 1646--1657].

The last column contains the number of all existing combinatorial non-isomorphic minimal drawings and a binary file of them (for n up to 16) and all sets we found so far for n = 17 to 20. The xy-coordinates are stored as 16-bit unsigned integer, see our order type page for more details on the file format. See also publications.
