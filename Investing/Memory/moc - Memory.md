# Memory

Memory IDMs (Micron, SK Hynix, Samsung, SanDisk, Western Digital, Kioxia) that design and fabricate DRAM, HBM, and NAND. Distinguished from Chips/ (fabless logic designers) and Semi Infrastructure/ (pure-play foundries) — memory makers are vertically integrated, owning both design and fab. Investment thesis driven by AI memory bottleneck (HBM scarcity, hyperscaler long-term supply agreements, NAND tier emerging in AI inference).
