# @RosannaInvests AEHR vs TRT positioning — proprietary FOX-XP wafer + Sonoma package equipment vs consumable BIBs, $41M Sonoma hyperscaler order, AEHR 1Y +974% vs TRT +434% vs SPY +29%

Rosanna Prestia (@rosannainvests) structural-positioning thesis on the [[Aehr Test Systems (AEHR)]] vs [[Trio-Tech International (TRT)]] debate, posted 2026-05-23. The crux: both compete in burn-in testing for AI chips but sit at **DIFFERENT layers of the test stack**, and the "smaller AEHR" framing collapses two distinct businesses. AEHR sells **proprietary equipment** to fabs (two platforms — FOX-XP wafer-level + Sonoma package-level); TRT sells **consumable boards** that go into competing equipment. Companion / counter-frame to [[BoringInvest 2026-04-24 - TRT unplanned position thesis - 9.77 entry, 10M direct offering, 111M cap 23M net cash, 1.79x EV-sales vs AEHR 50x, 82pct growth, staged exit to 450M cap|@boringinvest's 2026-04-24 TRT unplanned-position thesis]] — boringinvest framed the AEHR/TRT comparison via EV/sales (TRT 1.79x vs AEHR 50x) as the entry-multiple opportunity; Rosanna reframes the same pair via product-architecture differentiation that explains *why* the multiple gap is structural rather than just timing. Both views are coherent and complementary.

The structural reality, in Rosanna's framing: **same general category, different competitive positioning. Same general supply chain, different value capture.** Conclusion: "Pick accordingly or have BOTH!"

## Key Takeaways

- **AEHR runs TWO platforms; TRT runs ONE**. AEHR = FOX-XP (Wafer-Level Burn-In / WLBI) + Sonoma (Package-Level Burn-In / PLBI). TRT = Package-Level Burn-In Boards (BIBs) only — a single layer that competes with the *consumable* tier inside Sonoma-class equipment, not the equipment itself.
- **AEHR FOX-XP / Wafer-Level Burn-In moat**: tests entire 300mm wafers BEFORE dicing, **9 wafers parallel @ 3,500W each**. **Only validated solution for silicon photonics transceivers.** Multiple AI optical I/O customer wins. **Patent + WaferPak Contactor** = the moat. SiPh transceiver wins from this layer flow through the burn-in stack at companies like [[Lumentum (LITE)]], [[Coherent (COHR)]], [[Applied Optoelectronics (AAOI)]], [[Marvell Technology (MRVL)]], [[Sivers Semiconductors (SIVE.ST)]], [[POET Technologies (POET)]] — and SiC adoption at [[Wolfspeed (WOLF)]] / [[Navitas Semiconductor (NVTS)]] pulls the same WLBI architecture. Broader burn-in/test landscape context: [[PhotonCap 2026-05 - 7 companies own the 4-stage CPO test stack as TSMC COUPE production ramps, 100 seconds per PIC bottleneck]].
- **AEHR Sonoma / Package-Level Burn-In**: tests fully packaged AI processor ASICs (XPUs). **$41M record hyperscaler order in April 2026.** H2 FY26 bookings **>$92M**. Premium turnkey burn-in modules (BIMs).
- **TRT business profile**: Package-Level Burn-In **Boards** (BIBs only). Tests packaged chips. Sells the **consumable** boards, not the systems. Asian operations focus (Singapore, Malaysia, Thailand). **AI GPU orders $5.3M + $2.5M** — **one customer = 41% of revenue**. $10M ATM raise on April 24 at $9.50 post a +714% run. Insider selling flagged in the infographic (per the embedded `rosanna-569011-001.jpg`).
- **The structural mechanism (the actual point)**:
  - **"AEHR sells PROPRIETARY EQUIPMENT to fabs. TRT sells CONSUMABLE BOARDS that go into competing equipment."**
  - **"When a hyperscaler standardizes on Sonoma, they buy BIMs from AEHR not BIBs from TRT."**
  - **"When wafer-level adoption grows for photonics/SiC, AEHR captures the migration. TRT does not."**
- **MarketSurge proof** (per @MartyChargin's 3-image reply, image-only): 1Y total-return base-100 comparison through 2026-05-23 — **AEHR +973.67% / TRT +434.11% / SPY +28.76%**. AEHR has 2.25x TRT's return despite TRT's vertical +151% pivot-zone spike in late April. AEHR daily chart shows steady step-pattern through pivots 16.38 → 22.91 → 22.61 → 18.70 → 19.90 → 22.66 → 26.53 → 29.13 → 31.84 → 46.95 → 53.48 to current ~$95.02; TRT daily shows tight base 2.60–7.60 broken upward to 19.10 pivot. AEHR Mkt Cap $2.99B vs TRT $139.76M (~21x ratio) — but cumulative-return ratio is only 2.25x, suggesting the smaller-cap mean-reversion case is real *if* you treat them as the same business; Rosanna's argument is that you shouldn't.
- **Conclusion**: "Same general category. Different competitive positioning. Same general supply chain. Different value capture. The 'smaller $AEHR' framing treats two distinct businesses as one. They're not. Pick accordingly or have BOTH!" — explicit not-mutually-exclusive framing. Both can co-exist in a portfolio because they capture orthogonal pieces of the same end-customer's burn-in spend.
