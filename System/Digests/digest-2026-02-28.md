## Key Learnings
- **Parallel subagent audits scale vault maintenance**: Dispatching 3 focused subagents (one per audit scope) to deep-read every note and report placement recommendations worked cleanly — each returned in ~2 minutes with detailed per-note verdicts. This is the right pattern for vault-wide audits.
- **One-note subfolders are a smell**: The audit found that `AI Agents/`, `Background Agents/`, and `Learnings/` each had 1-2 notes with vague category names. Subfolder names that are too generic (e.g., "AI Agents" inside an Agents tree) provide zero navigational value. Rule of thumb: a subfolder needs 3+ notes and a specific scope to justify existing.
- **Summarized "Original Content" sections degrade note value over time**: The "over 40 percent" note had a paraphrased summary instead of verbatim source text. Re-fetching the full 2853-word thread and replacing the summary restored the note's archival integrity. The verify-original-content script caught the gap at 97% coverage post-fix.
