## Decisions Made
- **Task queue architecture**: plans/ideas live as markdown files in a queue directory (pending → active → done), separate from implementation beads which stay per-project. Avoids polluting bead queues with non-actionable items.
- **Subagent concurrency**: 2-3 subagents max, with a mandatory validation step (run tests + read diff) between completion and next spawn. Fire-and-forget doesn't work — subagents claim "done" but need independent verification.
- **Plutus investment memos**: Start writing structured post-analysis memos to the vault after significant trade decisions. Creates Layer 3 (institutional memory) cheaply.
- **Trigger mechanism for autonomous work**: cron every 30min + post-interaction check preferred over heartbeat alone (too slow at 1h).
