# Jev

TypeSafe AI's **System One Models** — a model class that gives up string generation to return type-safe structured decisions with calibrated probabilities, sampled in parallel rather than autoregressively. **Jev** is the first public model (early access, September 2026). This folder holds the primary source, the evidence behind its claims, and the use cases and ecosystem tools that have grown around it.
